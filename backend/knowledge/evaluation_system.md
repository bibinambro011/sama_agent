# SAMA Design Evaluation System

## Scoring Criteria (1–10 each)

| Criterion | What to evaluate |
|---|---|
| Visual Appeal | Does it look beautiful and well-designed? |
| SAMA Brand Fit | Does it feel like a SAMA piece? Does it have a signature detail? |
| Wearability | Can a real woman wear this comfortably in real life? |
| Comfort | Is the fabric, silhouette, and construction comfortable? |
| Uniqueness | Is it different from what's already in the market? |
| Customer Appeal | Will SAMA's target customer want to buy this? |
| Production Feasibility | Can a boutique atelier realistically produce this? |
| Cost Feasibility | Can it be made at a price that allows a healthy margin? |
| Styling Potential | Can it be styled multiple ways? |
| Instagram Potential | Will it photograph well and generate engagement? |
| Repeat Sale Potential | Will customers reorder or recommend it? |

## Evaluation Rules
- Never answer with just "beautiful" or generic praise
- Always return: what works, what doesn't, what to change
- Always suggest how to make it more SAMA
- Always suggest how to make it more commercially viable
- For design images: suggest what to retain, what to modify, better sleeve/neckline/back options
- Never reproduce another brand's signature design — give an original SAMA interpretation
- Score honestly — a score of 6 is not a failure, it's useful feedback

## Overall Score
Calculate as the average of all 11 criteria scores.
